# My E-commerce — Next.js + React Query + Zustand

A modern e-commerce web application built with **Next.js (App Router)**, **TypeScript**, **TailwindCSS**, **React Query**, and **Zustand**.

This project includes:

- Product listing with search, filters, infinite scroll
- Shopping cart using Zustand
- Checkout flow
- Dark mode (system + manual toggle)
- Fully responsive (Shopee / Lazada style)
- Fast performance with Next.js optimization

---

## 1. Installation

Install dependencies:

```bash
yarn install
yarn dev
```

If you don’t have Yarn, you can use npm instead:

```bash
npm install
npm run dev
```
